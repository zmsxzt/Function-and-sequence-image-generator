# 序绘 · 函数与数列图像生成器

中文交互式数学绘图工具。支持最多四条曲线对比、数列散点及连线、参数 a、坐标范围调整、滚轮缩放、拖拽平移和 PNG 导出。所有计算在浏览器内完成，无需 API 密钥或后端。

## 开发

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

开发服务器默认使用 5173 端口。生产构建：`npm run build`；本地验证产物：`npm run preview`；数学逻辑测试：`npm test`。

函数示例：`sin(x)`、`a*x^2`、`1/x`。数列示例：`1/n`、`(-1)^n/n`、`2*n+1`，n 从 1 开始。使用 `^` 表示乘方，`pi` 表示圆周率，三角函数使用弧度。参数 a 可在 −5 至 5 之间调整。数列视图最多显示 2000 项。

表达式由 mathjs 解析，只允许指定数学运算和函数，不执行任意 JavaScript。曲线通过有限采样绘制，极窄尖峰或复杂间断附近的图像可能需要调整坐标范围进一步观察。

成功发布后网址为：https://zsxz9470-bot.github.io/Function-and-sequence-image-generator/ 。首次部署完成前此地址不可用；可在 Actions 页面查看结果。构建使用相对资源路径，支持仓库子路径。

## 递推数列和圆锥曲线

在“数列图像”的每张卡片中，可选择“通项公式”或“递推公式”。例如递推式 `a(n-1)+a(n-2)`，初始项填 `1, 1`，会生成 1, 1, 2, 3, 5, 8…；填 `2, 1` 则生成卢卡斯数列。初始项按 a₁, a₂… 顺序提供，从这些初始项之后开始递推。支持 `n`、参数 `a`、常用数学函数和 `a(n-k)`（k 为正整数），需要提供足够的初始项。递推数列最多计算至第 2000 项；非实数或溢出会显示错误。

函数图像的“灵感起点”新增圆、椭圆、双曲线、抛物线。每个示例用两个显式分支绘制完整图形，最多四条曲线的规则仍适用；示例会自动开启“等比例坐标”，保证 X、Y 轴每单位长度一致。开启后坐标范围会扩展以适配画布，因此圆不会因屏幕比例变成椭圆。这里只提供常用圆锥曲线示例，不支持直接输入任意隐式方程。

## 更多数列类型

数列卡片支持四种定义方式：通项公式、递推公式、前 n 项和、前 n 项积。

- 通项公式：直接输入 aₙ，例如 `n^2`、`n^3`、`1/n^2`、`(n-1)%3+1`。
- 前 n 项和：输入被累加的单项公式，例如 `1/n`，得到调和部分和 Sₙ。
- 前 n 项积：输入被连乘的单项公式，例如 `n`，得到阶乘数列 n!。
- 累加和累乘始终从第 1 项开始计算，调整可视范围不会改变数列定义。最多计算至第 2000 项；阶乘等快速增长数列超出有限实数范围会显示错误。

灵感起点包含等差、等比、交错、倒数收敛、斐波那契、递推收敛、常数、平方、立方、倒数平方、三角数、周期、阶乘、调和部分和、等比部分和、裂项部分和，共 16 个示例。每个示例设置了适合观察的默认坐标范围，可继续修改表达式和范围。
